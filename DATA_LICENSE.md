# Data rights and attribution

The MIT license in this repository applies only to the original dataset tooling
in `scripts/`. It does **not** license the datasets, source workbooks, bid tabs,
annotations, external reference material, or historical experiment code.

Dataset provenance is recorded in `datasets/manifest.json`, the individual
dataset cards, and the retained source manifests. Government and other
third-party source materials retain their source-specific terms. No uniform
redistribution license was supplied with the research workspace, and this
repository does not assert one. A public repository is not itself a data license.

Research annotations and derived datasets are supplied for transparent
inspection and reproducibility. No additional project-wide data license is
assigned in this snapshot. Preserve the provenance and attribution files when
using or quoting the data. For source-specific permissions, consult the actual
source terms rather than applying the tooling license to data.
